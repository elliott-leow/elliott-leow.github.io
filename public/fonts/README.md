The Kevin Serif and Kevin Sans webfonts come from https://kevintngo.com/,
the typography reference requested for this site.

Source files (retrieved 2026-10-25):

- https://kevintngo.com/fonts/KevinSerif-Regular.woff2
- https://kevintngo.com/fonts/KevinSerif-Bold.woff2
- https://kevintngo.com/fonts/KevinSans-Regular.woff2
- https://kevintngo.com/fonts/KevinSans-Bold.woff2

The reference stylesheet describes these as hands traced from Hershey's
engraving faces: https://kevintngo.com/assets/site.css.
