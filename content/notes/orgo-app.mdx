Introductory organic chemistry requires a lot of visual reasoning, and this app intended to help with that. When I took introductory organic chemistry, our professor had a few animations throughout the course that stuck in my mind when solving problems.

## Default Controls

<ol className="orgo-guide-list">
  <li>
    <span className="orgo-guide-label">Movement</span>
    <ol type="a">
      <li>The default movement is using the <kbd>WASD</kbd> keys to translate the camera and using the arrow keys (<kbd>↑ ← ↓ →</kbd>) to rotate the camera</li>
      <li>Press “<kbd>M</kbd>” to enable fly mode. This allows you to fly like in a 3D video game using the <kbd>WASD</kbd> keys and use the mouse to rotate the camera.</li>
    </ol>
  </li>
  <li>
    <span className="orgo-guide-label">Creating Molecules</span>
    <ol type="a">
      <li>Enable the Build tool by pressing “<kbd>B</kbd>”. Clicking around will now place the selected atom (default is carbon)</li>
      <li>To chain atoms together into molecules, click on a carbon or hydrogen while the Build tool is still enabled.</li>
    </ol>
  </li>
  <li>
    <span className="orgo-guide-label">Deleting Atoms</span>
    <ol type="a">
      <li>Enable the Delete tool by pressing “<kbd>X</kbd>”. Click on atoms to delete them.</li>
    </ol>
  </li>
  <li>
    <span className="orgo-guide-label">Reacting Molecules</span>
    <ol type="a">
      <li>Enable the React tool by pressing “<kbd>T</kbd>”. You can draw arrows (starting at electrons and ending at atoms) to move electrons and possibly form new bonds. Press “<kbd>Return</kbd>” or “<kbd>↩</kbd>” to perform the reaction.</li>
    </ol>
  </li>
</ol>

## Features

<ol className="orgo-guide-list">
  <li>
    <span className="orgo-guide-label">Newman projections</span>
    <ol type="a">
      <li>Build your molecule. With the select tool, select the bond you want to look down. Press “<kbd>N</kbd>” to view along the bond like in a Newman projection. Press “<kbd>Q</kbd>” or “<kbd>E</kbd>” to rotate along the bond.</li>
    </ol>
  </li>
  <li>
    <span className="orgo-guide-label">Stereochemistry</span>
    <ol type="a">
      <li>Build your molecule. Hovering over an atom will tell you its stereochemistry if it is a stereocenter. Press “<kbd>[</kbd>“ to view the priorities of groups attached to the stereocenter.</li>
    </ol>
  </li>
  <li>
    <span className="orgo-guide-label">Chair/Boat Conformers</span>
    <ol type="a">
      <li>Click a 6 membered ring to be able to drag between chair flipped conformers.</li>
    </ol>
  </li>
</ol>
